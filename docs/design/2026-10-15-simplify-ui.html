A simpler Promise Graph

Option B on the seeded Larkspur data. A person does three jobs: look at the graph, review what changed, answer an escalation. The engine, the API, the MCP tools and the data model stay the same. Only the screens and the words change.

1Sidebar: three jobs, and it folds to icons

The rail shows one project at a time. A switcher at the top changes the project. Settings holds the agent tokens. The button at the bottom folds the rail to icons and opens it again. The app keeps the choice in a cookie, so the page loads at the right width with no jump. On a phone the rail stays a top bar, as today.

2Graph screen: fewer words, fewer controls

The header drops the commit id, the evidence revision, the keyboard hint and the "Create proposal" button. One line tells who changed the graph last and links to the activity list. The filters fold into one "Filter" button next to search and "Problems only". The canvas keeps zoom, fit and full screen.

5What goes away, what stays

Removed from the screen

  • Inbox, Proposals and History in the sidebar
  • Second project block in the sidebar (a switcher replaces it)
  • Keyboard hint line in the graph header
  • Head commit id and evidence revision in headers
  • "Create proposal" on the graph (now "New change set" in Review)
  • Axis menu with Weeks and Months marked "not implemented yet"
  • Resizable day columns and "Reset column widths" (PR #13)
  • Zoom preset menu and minimap
  • "I understand N records are pending" checkbox before approve

Moved, not removed

  • Side, departments, state, problem type, milestone: in "Filter"
  • Agent tokens: in Settings
  • History: in Activity, linked from the graph header
  • Rebase page: opens only on a conflict, as "Resolve conflict"
  • Change set editor: opens from "Edit"
  • Review basis: in "Technical details"

Not changed

  • Engine, loop states and the 7 problem types
  • Every act cites an exact quote
  • Agents only propose; a person approves
  • Merge checks: the same version, revision and digest as today
  • REST API, MCP tools, database, fixtures
  • Escalations screen, loop panel, event cards
